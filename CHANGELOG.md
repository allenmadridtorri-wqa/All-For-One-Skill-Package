# Changelog

All notable changes to the **All-For-One Skill Package** are documented in this file.

## [3.2.0] — The 130-Year Expertise Initiative (Photorealism, T4 Model Registry & Antigravity MCP Bridge)

### Added
- **Cross-Target >= 85% Token Budgeting System (`core/token-budget.ts`, `references/token-budget-architecture.md`)**: Enforced >= 85% token usage reduction across all **10 targets** (`antigravity`, `claude`, `chatgpt`, `custom-gpt`, `cursor`, `windsurf`, `cline`, `copilot`, `gemini-cli`, `opencode`), replaced bloated Custom GPT instruction concatenation with a < 4,000-char compact router, added `--compact` section-level markdown extraction in `core/knowledge-retrieval.ts`, and added `token-budget` CLI + `QA-TOKEN-BUDGET-85` QA check.
- **Verified Generative Model Capability Registry & Live HF Gradio Schema Inspector (`core/model-registry.ts`, `core/hosted-providers.ts`, `references/model-capability-registry.md`)**: Curated 10 open-weight models (`TripoSR`, `Stable Fast 3D`, `TRELLIS`, `TRELLIS.2`, `Hunyuan3D-2.0`, `SDXL Base 1.0`, `FLUX.1-schnell`, `Real-ESRGAN`, `Depth Anything V2 Small`, `Wan2.1 T2V-1.3B`) with code-vs-weight license separation, regional/revenue restrictions, T4 16 GB VRAM fit classification (blocking 24 GB+ `TRELLIS.2`), and strict-allowlist Hugging Face Gradio Space API schema inspection with HTTP 429 Colab T4 fallback.
- **Intelligent Task & Pipeline Router (`core/model-routing.ts`)**: Multi-stage routing for `product-vehicle`, `architecture-interior`, `natural-landscape`, `character-creature`, and `playable-3d-scene` with zero-paid-API enforcement, hosted HF Space -> Colab T4 fallback, and strict 5-way deliverable distinction (`Concept Image` != `AI Raw Mesh` != `Refined PBR Asset` != `Completed Scene` != `Playable Environment`).
- **Free & Open-Source Asset Catalog (`references/open-asset-ecosystem.md`, `OPEN_ASSET_SOURCES`)**: Documented CC0 sources (`Poly Haven`, `ambientCG`, `Kenney`, `Quaternius`) and per-asset license audit requirements for `OpenGameArt`.
- **Antigravity Local MCP-Compatible Bridge (`core/mcp-bridge.ts`, `scripts/mcp-bridge.ts`, `references/antigravity-colab-t4-bridge.md`)**: Added local stdio JSON-RPC 2.0 server and CLI exposing all **12 bridge tools** (`get_compute_profile`, `list_compatible_models`, `inspect_model_requirements`, `prepare_colab_job`, `validate_job_manifest`, `get_job_status`, `inspect_job_outputs`, `import_colab_results`, `validate_generated_asset`, `inspect_render_artifacts`, `get_token_budget_report`, `inspect_hosted_space`).
- **Structural 3D Asset & Visual Render Validation (`core/asset-validation.ts`, `core/qa-verification.ts`)**: Added real binary GLB/glTF inspection (`glTF` magic/version/JSON chunk, `POSITION`/`NORMAL`/`TEXCOORD_0`, `pbrMetallicRoughness`, node scale, external texture checks), FBX headers, and PNG IHDR dimension + visual criteria verification.
- **Photorealism Production Recipes & T4 Tests (`references/photorealism-production-recipes.md`, `scripts/v3_2-framework.test.ts`)**: Added 12-section authoritative domain guides (`33` indexed references total) and comprehensive unit/integration tests for all V3.2 systems.

### Changed
- **Automated Colab T4 Model Inference Runners & Strict Hardware Envelope (`core/cloud-rendering.ts`, `assets/colab/colab_blender_worker.py`, `references/cloud-colab-rendering.md`, `docs/CLOUD_RENDERING.md`)**: Implemented real per-model Colab T4 inference runners (`triposr`, `stable-fast-3d`, `sdxl-base-1.0`, `real-esrgan`, `depth-anything-v2-small`) with `config/inference_config.json`, OOM retry fallbacks, binary GLB/PNG validation, and SHA-256 `output_checksums.json`, alongside `15,360` MB T4 ceiling, dynamic system RAM checks, and `PREVIEW`/`LOOK_DEVELOPMENT`/`FINAL_T4_RENDER` profiles.
- **Refined 5 Specialist Skills & Cross-Target Installer (`skills/*/SKILL.md`, `core/installer-engine.mjs`, `scripts/install.mjs`, `scripts/afo.ts`)**: Integrated 130-year expertise workflows cleanly in plain step-by-step format, expanded installation to 9 targets (`claude`, `antigravity`, `chatgpt`, `cursor`, `windsurf`, `cline`, `copilot`, `gemini-cli`, `opencode`) + compact `custom-gpt` bundle, and added `token-budget`, `inspect-space`, `models`, `route`, `validate-asset`, `prepare-colab-t4`, and `mcp-tools` CLI subcommands.

## [3.1.0] — Single-AI-First Engineering & Creative Production Upgrade

### Added
- **Single-AI-First Architecture (`core/single-ai.ts`, `references/single-ai-architecture.md`)**: Set **`ECONOMY`** (1 primary AI model, sequential execution, compact context reuse, local deterministic offloading) as the default mode, added **`BALANCED`** (internal lens switching + separate QA phase), and gated **`ACCELERATION`** behind explicit `assertExecutionModeAllowed` user approval.
- **Dedicated Cinematic Production Engine (`core/cinematic-production.ts`, `references/cinematic-production-engine.md`)**: Structured screenplay beats, multi-scene/shot plans (e.g., 90s @ 24fps = `2,160` frames), dependency tracking, frame-range chunk splitting, atomic checkpoints, missing-frame disk reconciliation (`reconcileShotFramesFromDisk`), resume recovery, and honest `ffmpeg` assembly gating (`buildVideoAssemblyPlan`).
- **Cloud & Google Colab GPU Rendering (`core/cloud-rendering.ts`, `assets/colab/colab_blender_worker.py`, `references/cloud-colab-rendering.md`)**: Added `RemoteRenderProviderRegistry`, hardware offload routing (`evaluateHardwareRenderRouting`), SHA-256 asset manifest packaging, Drive-backed `.ipynb` notebook generation, resumable GPU-else-CPU Colab worker, and PNG magic-byte verification (`reconcileRemoteRenderOutputs`).
- **Engineering Structure, Feasibility & Status Gates (`core/engineering-intelligence.ts`)**: Added `analyzeProjectStructure`, `assessTechnicalFeasibility`, and `ImplementationStatusTracker` blocking unverified `IMPLEMENTED -> VERIFIED` transitions without executed tests.
- **Compact Recovery Memory & Immutable Decisions (`core/production-memory.ts`)**: Added `buildCompactContextSummary()`, immutable decision IDs, and known-bug, task-progress, build-history, and asset-reference tracking.
- **CLI & Documentation**: Added `single-ai-check`, `colab-check`, and `cinematic-plan` CLI subcommands (`scripts/afo.ts`), `scripts/v3_1-framework.test.ts`, and comprehensive V3.1 guides (`docs/*.md`, `MIGRATION_V3_TO_V3_1.md`).

### Fixed & Security-Hardened
- **Blender Bridge Python Injection & Confinement (`core/blender-bridge.ts`, `assets/blender/export_engine_asset.py`)**: Replaced unsafe `r"..."` path interpolation with `serializePythonString()` (`JSON.stringify`), `validateBlenderWorkspacePath()` newline/traversal/root confinement, and Python `--base-dir` `os.path.realpath` enforcement; added LODs, Smart UV, IK/FK + facial armatures, cloth/hair, volumetrics, compositor glare, tracked camera keyframes, and `splitFrameRange` / `findMissingFramesInRange`.
- **Windows PowerShell & ESM Compatibility (`install.ps1`, `core/installer-engine.mjs`, `scripts/*.ts`)**: Added `-Yes`, `-Verify`, `-CheckTools` to `install.ps1` with `-Force -Yes` parity and `$LASTEXITCODE` propagation; added `EPERM`/`EBUSY`/`EACCES` rename retry in `atomicWriteFileSync`, Windows Blender install folder probing, `ffmpeg` probing, and `pathToFileURL` ESM entrypoints.
- **Provider Error Credential Redaction & Response Caching (`core/model-adapter.ts`)**: Added SHA-256 prompt response caching and `redactSecrets()` sanitization on provider error fallbacks across OpenAI-compatible, Anthropic-compatible, Google-compatible, and local HTTP adapters.

## [3.0.0] — V3 Advanced Engineering Upgrade

### Added
- **Security Hardening Module (`core/security.ts`)**: Added symlink-aware `assertSafeSubpathSync`, temp-sibling `atomicWriteFileSync`, exclusive `wx` lockfiles (`withAdvisoryLock`), `redactSecrets` / `scanForSecrets` (API keys, Bearer tokens, PEM blocks, DB URIs), `assertDestructiveApproved`, and `isDangerousShellCommand`.
- **Engineering Intelligence (`core/engineering-intelligence.ts`)**: Extended architecture, multi-manifest dependency analysis (`package.json`, `Cargo.toml`, `CMakeLists.txt`, `.csproj`, `project.godot`, `.uproject`), deprecated/incompatible API checks, error-log diagnosis, and code review across 8 stacks (all 6 game engines + `web-fullstack` + `general-software`).
- **Headless Blender Automation Bridge (`core/blender-bridge.ts`, `assets/blender/export_engine_asset.py`, `references/blender-automation-pipeline.md`)**: Added safe `detectBlenderInstallation()`, sandboxed CLI execution (`--background --factory-startup --python-exit-code 1`), and hardware-bounded `bpy` script generation (metric scale, Geometry Nodes, Principled BSDF, 3-point lighting, optional Rigify/physics, Cycles/EEVEE, FBX/GLB export). Marks Blender steps `UNVERIFIED` when absent.
- **Game-Engine Asset Pipeline Validation (`core/asset-pipeline.ts`, `references/game-engine-asset-pipelines.md`)**: Added `ENGINE_ASSET_EXPORT_SPECS` and binary GLB/glTF/FBX validation (`validateExportedAsset` checking meshes, UVs, normals, materials, skins, animations, and non-unit scales).
- **Visual Iteration Controller (`core/visual-iteration.ts`)**: Enforces `Create -> Render -> Inspect -> Diagnose -> Improve -> Re-render`, validates PNG/JPEG/WEBP file signatures, rejects existence-only claims as `PARTIALLY_VERIFIED`, and preserves highest-scoring verified renders.
- **Model Adapter Abstraction (`core/model-adapter.ts`)**: Added zero-cost `OfflineDeterministicAdapter` default and optional `ConfigurableModelAdapter` (`local-http` / `env-configured`) with graceful offline fallback.
- **13-Domain V3 Evaluation Suite (`evals/suite-v3.json`, `scripts/v3-framework.test.ts`)**: Added 39 V3 benchmark cases (159 total cases with V2 baseline) and 10 V3 unit/integration test suites.
- **V3 Documentation**: Added `SECURITY_AUDIT.md`, `MIGRATION_V2_TO_V3.md`, and `docs/BLENDER_AND_ASSET_PIPELINES.md`; updated `README.md` and `VERIFICATION_REPORT.md`.

### Changed
- **Installer Integrity & Guards (`core/installer-engine.mjs`, `scripts/install.mjs`, `install.sh`, `install.ps1`)**: Added symlink escape blocking, atomic writes, `.afo-install.lock` locking, SHA-256 `verifyInstallIntegrity` (`--verify`), `detectExternalTools` (`--check-tools`), and explicit `--yes` approval gating for `--force`.
- **Inter-Agent Collaboration (`core/collaboration.ts`)**: Added `AgentMessage` exchange (`REVIEW_FEEDBACK`, `FAILURE_ESCALATION`, `HANDOFF`), `raiseConflict` / `resolveConflict`, `registerArtifact`, and `decomposeGoalIntoTasks`.
- **Corruption-Protected & Secret-Scrubbed Memory (`core/production-memory.ts`, `core/production-intelligence.ts`)**: Added automatic secret scrubbing, `.afo-memory-state.json` SHA-256 checksums (`verifyIntegrity()`), `recordSuccessPattern`, `preserveKnownGoodOutput`, `getRecurringProblems`, and hardware-clamped `runBoundedSchedule`.
- **Provenance-Aware Knowledge Retrieval (`core/knowledge-retrieval.ts`, `references/index.json`)**: Expanded catalog to 25 documents (`version: 3.0.0`), added `official-spec` / `engine-profile` weighting, deduplication, outdated-reference detection, and query caching.
